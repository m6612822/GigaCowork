# Тестовые данные

Все данные синтетические; компании, бренды, сотрудники и номера вымышленные.

- `01_ful_from_1c.xlsx` — 20 ФУЛ.
- `02_cloud_register.xlsx` — 45 строк Cloud.
- `03_employees.xlsx` — 11 сотрудников, включая ассистента и руководителя.
- `04_expected_result.xlsx` — эталон по принятому алгоритму.
- `generate_data.py` — генератор исходных Excel-файлов.

Покрыты: три группы; повтор в Cloud и внутри пачки; новый поставщик; предпочтительный логист в отпуске и уволенный; мультимодальная группа без доступных сотрудников; отсутствие номера заказа, способа доставки и страны; дата ФУЛ раньше максимальной даты в Cloud; варианты написания поставщика.

Допущения: ключ повтора — номер заказа; без номера строка не создаётся; при отсутствии страны или способа доставки строка создаётся с «не определено» и пустым логистом; старая дата не блокирует создание, но требует проверки; история поставщика считается по всем строкам Cloud, загрузка — по статусу «в работе»; при равенстве используется сортировка по ФИО.
