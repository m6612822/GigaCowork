# Навык: распределение ФУЛ

## Когда применять
Применяй навык, когда приложены три Excel-файла: выгрузка ФУЛ из 1С, реестр Cloud и список сотрудников. Пользователь может отправить файлы без текста. Не проси пользователя повторять бизнес-правила.

## Порядок работы
1. Определи три файла по заголовкам колонок, а не по имени файла. Внутри книги лист может называться произвольно.
2. Запусти скрипт `scripts/process_ful.py`, передав пути к файлам и папке результата:
   `python scripts/process_ful.py --ful <path> --cloud <path> --employees <path> --output-dir <directory>`
3. Не рассчитывай распределение самостоятельно и не переопределяй вывод скрипта.
4. Если скрипт завершился с ошибкой, сообщи точный текст ошибки и попроси исправить входные файлы. Не выдумывай результат.
5. Верни пользователю файл `result.xlsx` и краткую сводку: количество ФУЛ, новых строк, повторных отправок и позиций, требующих внимания.

## Правила ответа
- Не подставляй отсутствующие значения. В выходных данных используй «не определено» или пустого логиста в случаях, предусмотренных скриптом.
- Укажи, что решения и основания находятся на листе «Журнал решений».
- Не заявляй о записи в Cloud или 1С: навык только формирует файл.
- Не раскрывай внутренние рассуждения модели; сообщай только фактические основания из журнала.

## Ограничения
Работа только с приложенными Excel-файлами. Не использовать сеть, коннекторы, API 1С или Cloud. Внешние Python-библиотеки, кроме openpyxl и xlrd, не использовать.
